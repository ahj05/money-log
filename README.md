# 둘의 하루 (Date Route Curator)

> **"검색은 줄이고, 데이트는 더 길게."**  
> 출발지에서 첫 장소까지의 이동 정보와 취향에 맞는 데이트 코스 3가지, 주변 추천 식당을 함께 비교할 수 있는 모바일 웹 목업 서비스입니다.

---

## 🌟 주요 기능

1. **데모 시나리오 기반 체험**
   - 별도 가입 절차 없이 데모 계정으로 즉시 진입
   - 사전 준비된 성수·서울숲 데이트 시나리오 제공

2. **데이트 코스 3종 비교**
   - **여유로운 서울숲** (산책과 대화 중심): 서울숲 → 페이지27 → 루프카페
   - **성수 감성 탐방** (숍과 디저트 중심): 연무장길 → 스튜디오마켓 → 어반디저트
   - **실내 문화 코스** (전시와 독서 중심): 아트룸 → 북라운지 → 시네마카페

3. **이동 정보 & 카카오맵 연동**
   - 건대입구역 기준 첫 목적지까지의 예상 소요 시간 및 대중교통(지하철+도보) 경로 안내
   - 카카오맵 길찾기 링크 원클릭 연결

4. **주변 추천 식당 큐레이션**
   - 코스 장소 기준 **도보 20분 이내**, 샘플 평점 **4.0 이상** 식당 추천
   - 식당 상세 모달(평점, 도보 시간/거리, 예상 가격대, 카카오맵 위치 보기)

---

## 🛠 기술 스택

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Library**: React 19
- **Styling**: Vanilla CSS (Mobile-First Responsive Layout)
- **Deployment**: Vercel

---

## 🚀 로컬 실행 방법

```bash
# 의존성 설치
npm install
# 또는 pnpm install

# 개발 서버 실행
npm run dev
# 또는 pnpm dev

# 프로덕션 빌드
npm run build
npm run start
```
